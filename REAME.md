# Bash Learning

## Goal

Learn Bash from beginner level to practical Linux automation through YouTube and hands-on practice.

## Learning Path

1. **Bash Fundamentals**

   * Terminal basics
   * Commands and arguments
   * Variables
   * Quoting
   * Input/output
   * Pipes and redirection

2. **Bash Scripting**

   * Scripts
   * Conditions
   * Loops
   * Functions
   * Arrays
   * Exit codes
   * Arguments

3. **Linux Automation**

   * Filesystem automation
   * Processes
   * Permissions
   * Users and groups
   * Environment variables
   * Cron jobs

4. **Advanced Bash**

   * `grep`
   * `sed`
   * `awk`
   * `find`
   * `xargs`
   * Regular expressions
   * Command substitution
   * Error handling

## Project-Based Practice

Build small scripts while learning:

* [ ] File organizer
* [ ] Backup script
* [ ] System information tool
* [ ] Log analyzer
* [ ] Process monitor
* [ ] User-management helper
* [ ] Automated project setup script
* [ ] Linux security checker

## Rule

**Watch → Reproduce → Modify → Build**

Do not only watch tutorials. Type the commands yourself and build something after every major topic.

## YouTube

Look for complete Bash/Linux courses rather than random individual videos.

Recommended search topics:

* `Bash scripting full course`
* `Linux command line full course`
* `Bash scripting projects`
* `Advanced Bash scripting`

## Completion Goal

Be able to look at a repetitive Linux task and think:

> **"I can automate this with Bash."**
